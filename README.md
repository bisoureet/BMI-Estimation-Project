# BMI-Estimation-Project
Machine learning project using Linear Regression to estimate BMI from gender, height, and weight.

This project applies machine learning techniques to estimate Body Mass Index (BMI) from gender, height, and weight. The dataset is preprocessed to encode gender numerically and calculate BMI using the standard formula. A Linear Regression model is trained and evaluated using Mean Squared Error (MSE) and R² score. The program also allows user input to predict BMI and classify results into categories (Underweight, Normal weight, Overweight, Obese) based on World Health Organization (WHO) standards.
